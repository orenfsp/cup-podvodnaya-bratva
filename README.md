Платформа «Отклик» (MVP)
Анонимная платформа для сбора, маршрутизации и обработки обращений, жалоб и кризисных сигналов в образовательных учреждениях.

Основные возможности
Анонимная подача обращений школьниками, родителями и педагогами с прикреплением файлов.

Автоматическая детекция кризисных маркеров с мгновенным повышением приоритета обращения.

Трекинг статуса по уникальному коду в формате otk-XXXX-XXXX.

Разделение прав доступа по ролям: заявитель, эксперт, оператор, администратор.

Панель для работы с обращениями, сменой статусов и чатом.

Технологический стек
Backend: Python, FastAPI, SQLAlchemy, Uvicorn

Database: PostgreSQL

Frontend: HTML5, CSS3, JavaScript

Containerization: Docker, Docker Compose

Инструкция по запуску
Установите на компьютер Docker и Docker Compose.

Откройте терминал в корневой папке проекта.

Запустите проект командой:
docker compose up --build -d

После запуска бэкенд и база данных будут активны. Документация API доступна по адресу http://localhost:8000/docs.
